What we found (checked October 2026; prices and rules change, re-check before acting):
- X: put the finding, chart or map in the post itself and the link in the first
  reply. Several sources say link posts get less reach; one analysis of X's
  published algorithm found no explicit link penalty, so it's disputed.
- X Premium (blue tick) is $8/month on the web. X doesn't publish its effect on
  reach; third-party estimates say free accounts get very little and Premium mainly
  lifts replies. Worth paying only once posting weekly.
- X API: pay-per-use for new developers (no free tier since Feb 2026), about $0.015
  per post or $0.20 for a post with a link. Cheap enough to automate.
- Automation: fully automatic "new page" posts get little engagement. Better: each
  deploy script drafts the post (key finding + chart image), one command approves
  and posts it.
- LinkedIn matters more than X for being discovered as an ML scientist (résumé,
  recruiters). The same draft-and-approve flow can cover it; its posting API is more
  restricted.
- Medium: use "Import a story" so the copy names the site page as the original
  (canonical) and doesn't compete with it in search; pasting by hand loses that.
  Interactive charts don't carry over, so post a summary with images and a link.
- Substack: can't point a copy back to the original, so a full copy could outrank the
  site. Use it later, if at all, as an email newsletter that links to the site.
